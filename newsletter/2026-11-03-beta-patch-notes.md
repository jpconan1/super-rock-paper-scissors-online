## About the Progression System:

I added this because I wanted players to come back and play again and again. The game lacked a hook.

So now you start with only Lucky unlocked. Players can play matches to earn XP and unlock more classes. Once you unlock all the classes and win an online match with Joe, you Prestige: you get a special animation and Emblem for your profile and have finished the game’s content (for now!)

My goal with this system is player retention. This is my first game and if I managed to get an organic player base I’d be over the moon.

Just a reminder that this is a non-commercial community project. I’m committed to never charging for any part of the game or putting paid ads on it. I’ll never sell booster packs or micro-transactions for classes or premium Emblems or any nonsense like that. The progression system is for fun.

In that spirit, I also added a cheat that unlocks all the classes instantly if you don’t want to bother. Enter the Konami code in the lobby settings! There’s no penalty or restriction (besides an indicator on your player card) and it’s instantly reversible.
